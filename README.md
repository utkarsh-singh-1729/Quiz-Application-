# QuizMaster 🧠⚡

A modern quiz application built with React and Firebase, featuring real-time updates, user authentication, and interactive quiz creation.


## Features ✨
- 🔒 User Authentication (Email/Password)
- 📝 Create Custom Quizzes with Multiple Question Types
- 🎯 Take Quizzes with Real-Time Feedback
- 📊 Track Scores and Results
- 🔥 Real-Time Database with Firestore
- 📱 Responsive Design
- 🔄 State Management with React Context

## Technologies Used 🛠️
- **Frontend**: React, React Router
- **Backend**: Firebase Authentication, Firestore
- **Styling**: CSS Modules/Material-UI
- **State Management**: React Context API

## Installation 📥

### Prerequisites
- Node.js v16+
- Firebase account
- npm/yarn

```bash
# Clone repository
git clone https://github.com/yourusername/quizmaster.git
cd quizmaster

# Install dependencies
npm install
# or
yarn install
